Плагин Робокасса24 <b>НЕ является</b> официальным плагином MogutaCMS<br>
Плагин содержит серверную часть, все данные из настроек плагина передаются и обрабатываются с участием серверов ООО "МПМ" ИНН 1838002128<br>
Оферта Обработчика персональных данных, регистрация Оператора персональных данных (ссылки)<br>
Если вам требуется персональное соглашение - запросите на apps@all2crm.ru
<details>
      <summary>Для чего этот плагин</summary>
      <p>Подключение интернет-магазина MogutaCMS к платёжному агрегатору Робокасса с возможностью передачи оплаченных заказов в CRM Битрикс24</p>
</details>
<details>
      <summary>Описание работы</summary>
      <p>Плагин по настройкам формирует платёжную форму для покупателя<br>Магазин перенаправляет покупателя на платёжную форму<br>Робокасса принимает оплату, отбивает чек и высылает покупателю<br>Плагин помечает заказ как «Оплаченный» и формирует ответ для Робокасса<br>Плагин передаёт оплаченный заказ в Битрикс24<br></p></details>
<details>
<summary>Сценарии использования</summary>
      <ul>
        <li>Принять оплату за товары или услуги</li>
        <li>Один чек, простая продажа: получение оплаты магазином и отправка чека покупателю</li>
        <li>Один чек, продажа с сопровождением заказа: получение оплаты магазином, отправка чека покупателю, передача оплаченного заказа в Битрикс24 для дальнейшей обработки и учёта</li>
        <li>Два чека, продажа на сайте товаров с обязательной маркировкой Честный Знак: получение предоплаты магазином, отправка первого чека покупателю, передача оплаченного заказа в Битрикс24, комплектация и отправка заказа, выдача итогового чека покупателю. Первый чек, на предоплату, формируется Робокасса по платёжной форме плагина. Второй чек, на окончательный расчёт с марками Честного Знака, формируется Битрикс24. Марки Честного знака набираются в Сделку Битрикс24 на этапе комплектования и отгрузки заказа покупателю. Второй чек формируется Робокасса из Битрикс24 по отгрузке заказа либо по получению заказа. Второй чек выводит конкретные экземпляры товара из оборота в системе Честный Знак.</li>
      </ul>
</details>
<details>
      <summary>Общая логика работы плагина</summary>
      <p>Стоимость доставки заказа включается в общую стоимость заказа и передаётся в чек как "Доставка". Сведения о доставке(получатель, адрес и прочее) передаются дополнительно в Битрикс24 как содержимое поля Битрикс24<br>Ставка НДС для всех позиций чека едина и определяется настройками плагина, "НДС в том числе" для всех ставок кроме "Без НДС"<br>Покупатель заказа передаётся в Битрикс24 как Контакт. Если нет Подходящего контакта в Битрикс24 - будет создан новый Контакт<br>Заказ магазина передаётся в Битрикс24 как Сделка. Номер счета на стороне Робокасса = (номер заказа в магазине без префикса) * 10. Каждый заказ магазина - новая Сделка Битрикс24<br>Если товар заказа отсутвует в Битрикс24, будет создан новый товар. Товары на стороне Битрикс24 различаются по сочетанию Наименования и GTIN. При наличии в заказе сайта "Товар" и "Товар" с установленным GTIN в допполе товара(поле указывается настройками плагина), на стороне Битрикс24 будут созданы два разных товара.  Варианты товаров магазина становятся простыми товарами Битрикс24</p>
</details>

      <summary>Установка</summary>
      <p>Как и любой плагин для MogutaCMS, загрузить из Маркет или распаковать архив с плагином в /mg-plugins/ вашего магазина. Если установка из ZIP архива - напишите на apps@all2crm.ru указв домен магазина, добавим в список разрешённых. Если у Вас есть аккаунт разработчика MogutaCMS плагин можно использовать как свой, изменив имя папки/архива</p>

<details>
      <summary>Настройки</summary>
      <p>Настройки для Робокасса<br>
        Название для менеджера: - название способа оплаты для админки магазина<br>
        Название для клиента: - название способа оплаты, который увидит посетитель сайта если есть нессколько способов оплаты<br>
        Логин, пароль1 и пароль2 - из настроек магазина в ЛК Робокасса https://partner.robokassa.ru/Home - Настройки - Технические настройки<br>
        Система налогообложения - будет указана в чеке покупателю. Выбирайте "Общая СН" если используте Робочеки вне зависимости от системы налогообложения вашей компании. При использовании Робочеков агрегатор Робокасса выступает в роли "Платёжного агента"<br>
        Вариант платежа - в чеке будет указан технологический параметр full_payment либо full_prepayment для каждой позиции. При простой продаже используйте "Полный рассчёт". При продаже товаров Честный Знак предполагается два чека на заказ, первый - предоплата, второй - окончательный. При продаже товаров Честный Знак используйте "100% предоплата(первый чек из двух)"<br>
        GTIN в доп поле товара - дополнительное поле Товара MogutaCSM в котором указан GTIN для Честный Знак. Можно выбрать существующее и создать новое поле https://wiki.moguta.ru/settings/dopolnitelnye-polya<br>
        НДС, включенный в цену - ставка действует на все товарные позиции чека<br>
        Метод шифрования - метод шифрование из ЛК Робокасса https://partner.robokassa.ru/Home - Настройки - Технические настройки. Лучше везде установить "sha256"<br>
        Ссылки для указания в сервисе - эти URL нужно скопировать из настроек плагина и указать ЛК Робокасса https://partner.robokassa.ru/Home - Настройки - Технические настройки<br>
        ЛК Робокасса https://partner.robokassa.ru/Home - Настройки - Технические настройки метод передачи - везде POST<br>
        <br>Настройки для Битрикс24<br>
        Битрикс24 WebHook - Входящий вебхук Битрикс24, требуемые права "CRM, Торговый каталог". Формат "https://домен.портала.зона/rest/N/n3kxw65fv8v90t/" - протокол в начале и закрывающий слэш на конце. Если не заполнено - нет попыток передачи<br>
        Битрикс24 Ответственный - целое число<br>
        Битрикс24 ID Источник - WEB, STORE и прочие<br>
        Битрикс24 ID Категории Сделки - целое число<br>
        Битрикс24 ID поля Сделки для ID заказа сайта - вида UF_CRM_1754287011<br>
        Битрикс24 ID поля Сделки для ID заказа Робокассы - вида UF_CRM_1754287011<br>
        Битрикс24 ID поля Сделки для Робокасса OpKey - вида UF_CRM_1754287011<br>
        Битрикс24 ID поля Сделки для сведений о доставке - вида UF_CRM_1754287011<br>
        Битрикс24 ID Инфоблока Товарного каталога - целое число<br>
        Битрикс24 ID поля Товара для GTIN - вида UF_CRM_1754287011<br>
        Битрикс24 ID поля Контакта для id покупателя магазина - вида UF_CRM_1754287011<br>
        <br>
        Настройки плагина заполняются без дополнительных кавычек, как есть, правильно UF_CRM_1754287011, WEB и 34, не сработает "UF_CRM_1754287011", "STORE" и "34"
      </p>

<details>
      <summary>Совместимость</summary>
      <p>Плагин работоспособен для MogutaCMS версии 11 и больше, любого облачного портала Битрикс24, коробочного Битрикс24(CRM 25.000 и больше), кодировка UTF-8 <br>
        Плагин совместим с плагином "Комплект товаров" https://moguta.ru/plugins/dopolnitelnye-elementy/komplekty-tovarov и тестировался с версией Комплект товаров, Версия 1.3.36, Автор - Дарья Чуркина. Комплект товаров заказа передаётся в чек Робокасса и Битрикс24 по отдельным позициям с ценами указанными для позиций комплекта, GTIN - для товара или варианта товара из комплекта<br>
        Плагин тестировался с доставками: Доставка СДЭК(плагин), Курьер, Почта<br>
        Плагин не вызывает конфликтов при одновременной установке с плагином "Оплата ROBOKASSA" https://moguta.ru/plugins/integratsiya/dopolnitelnye-oplaty/oplata-robokassa но сервис Робокасса передает результаты обработки платежа только на один из наборов URL. Любой из плагинов может вызвать платёжную форму для посетителя сайта и Робокасса примет оплату, но корректно обработать результат платежа(показ страницы сайта, пометка заказа "Оплачен") сможет только один из плагинов, чьи URL указаны в настройках магазина в ЛК Робокасса. Обратите внимание - наборы URL отличаются<br>
      </p>
